# ภาพรวมงานวิจัย EA ทองคำ XAUUSD (พ.ย. 2026)

## 1. เป้าหมายและเงื่อนไข
- สินค้า: ทองคำ XAUUSD, โบรกเกอร์ Exness (เวลาเซิร์ฟเวอร์ GMT+0), MetaTrader 5
- ทุน: 300 USD (บัญชี Standard หรือ Cent 30,000 USC)
- เป้าหมาย: กำไรเร็วที่สุด ออกไม้บ่อย DD สูงสุดไม่เกิน 50%
- ทดสอบเฉพาะปีล่าสุด (พ.ย. 2025 – พ.ย. 2026) เพราะพฤติกรรมทองเปลี่ยนไปมาก

## 2. วิธีทดสอบ (ใช้กับทุกกลยุทธ์)
1. ข้อมูล: real tick ของ Dukascopy (bid/ask ทุก tick) แท่งเทียนสร้างจาก tick เวลา UTC
2. เข้าไม้: tick แรกหลังแท่งสัญญาณปิด (Buy ที่ ask, Sell ที่ bid) ตรวจ SL/TP/ออกตามเวลาทุก tick หัก spread จริง
3. กำหนดชุดค่าที่จะลองไว้ก่อนรัน ห้ามไล่ปรับหลังเห็นผล
4. แบ่งข้อมูล: เลือกค่าจากช่วง พ.ย.–มิ.ย. แล้วดูผลช่วง ก.ค.–พ.ย. ที่ไม่ได้ใช้เลือก
5. เทียบการสุ่มทิศ: สลับทิศ Buy/Sell แบบสุ่ม 10,000 รอบ ผลจริงต้องชนะ ≥ 95% (พิสูจน์ว่าไม่ได้กำไรเพราะทองขึ้นอย่างเดียว)
6. ตรวจการปรับเกิน (overfit): PBO < 0.2 และ Deflated Sharpe > 0.95 เมื่อเทียบหลายชุด
7. จำลองเงิน: ทุน 300, ความเสี่ยง % ต่อไม้, lot ขั้นต่ำ 0.01 เข้าได้เฉพาะเมื่อเสี่ยงจริง ≤ 5.5%, หยุดเมื่อ DD 50%
8. ยืนยันสุดท้าย: MT5 Strategy Tester (Exness real tick) และ demo 4–8 สัปดาห์ ด้วย compare_demo.py

## 5. บทเรียนสำคัญ
1. ทองปีนี้วิ่งเป็นเทรนด์แรง: ระบบตามเทรนด์บน H1 ได้ผล ระบบกลับตัว (mean reversion) และ SMC ขาดทุนทุก TF
2. M5/M1 แทบทุกตัวขาดทุน spread (~0.6 USD) กิน 0.1R ต่อไม้ ยกเว้นเมื่อยืดคาบอินดิเคเตอร์ให้เท่าเวลาบน H1 (~60–80 ชั่วโมง) + กรองเทรนด์ D1
3. ช่วงเวลา 00:00–07:00 UTC (เอเชีย) และการถือไม้จนปิดวัน มี edge ชัด (ORB, DMA, XMS)
4. TP ตายตัวตัดกำไรของระบบตามเทรนด์ (SSL Hybrid Strategy จาก TradingView ได้ +0.05R เทียบกับถือจนกลับทิศ +0.27R)
5. บัญชี Standard 300 ใช้ได้เฉพาะระบบที่ SL แคบ (≤ ~16 USD) ระบบ SL กว้างต้องใช้ Cent
6. อัตราผ่านจริงประมาณ 1 ใน 10 การทดสอบหลายตัวย่อมมีตัวผ่านโดยบังเอิญ จึงต้องมีด่านสุ่มทิศ แบ่งช่วง และ demo

## 6. ข้อจำกัด
- ทดสอบปีเดียว ผลปีหน้าอาจต่างมาก โดยเฉพาะถ้าทองแกว่งในกรอบ
- ค่าพารามิเตอร์บางตัวเลือกจากปีเดียวกับที่ทดสอบ (SENTINEL M15/M5, XMS) ผลจริงคาดว่าต่ำกว่า (ประมาณครึ่งหนึ่ง)
- ยังไม่หัก swap; slippage 0.10 USD ลดกำไร 5–13%
- EA ที่เขียนใน cloud ยังไม่ได้คอมไพล์ใน MT5 จริง
