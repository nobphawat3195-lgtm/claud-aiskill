## ที่มา
SSL Hybrid (Mihkel00, TradingView) ผ่านการทดสอบเป็น 1 ใน 10 อินดิเคเตอร์รอบแรก แล้วพัฒนาต่อ: ยืดความยาว HMA ให้เท่า ~60–80 ชั่วโมงทุก TF, เพิ่มตัวกรองเทรนด์ D1, รวม MACD (รอบ 2) เป็นโหมดเทอร์โบ

## LOGIC
- เส้นบน = HMA(High, N), เส้นล่าง = HMA(Low, N) บนแท่งที่ปิดแล้ว
- ปิดเหนือเส้นบน = ขาขึ้น, ปิดใต้เส้นล่าง = ขาลง สถานะกลับทิศ → ปิดไม้เดิม เปิดไม้ใหม่
- MACD: ฮิสโตแกรม > 0 ขาขึ้น / < 0 ขาลง
- SL 1.5 × ATR(14), ไม่มี TP, lot = ทุน × ความเสี่ยง% ÷ ระยะ SL, หยุด EA ที่ DD 50%
