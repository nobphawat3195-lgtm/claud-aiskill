## LOGIC การเข้าไม้
1. **เส้น SSL**: เส้นบน = HMA ของ High, เส้นล่าง = HMA ของ Low ความยาวประมาณ 60–80 ชั่วโมง (H1 60 แท่ง, M15 320 แท่ง, M5 960 แท่ง)
2. **สถานะ**: แท่งปิดเหนือเส้นบน = ขาขึ้น, ปิดใต้เส้นล่าง = ขาลง, อยู่ระหว่างเส้น = คงสถานะเดิม
3. **ตัวกรอง D1** (M15 และ M5): เปิดไม้เฉพาะทิศเดียวกับเทรนด์รายวัน (ราคาปิดเมื่อวาน เทียบ EMA20 ของ D1) H1 ไม่ใช้ตัวกรอง
4. **เข้า/ออก**: สถานะกลับทิศ → ปิดไม้เดิมของเครื่องยนต์นั้น แล้วเปิดไม้ทางใหม่ทันที SL = 1.5 × ATR(14) ไม่มี TP ถือจนสัญญาณกลับทิศ
5. **ขนาด lot** = ทุน × ความเสี่ยง% ÷ ระยะ SL ถ้าต้องใช้ lot ขั้นต่ำแล้วเสี่ยงเกิน 5.5% จะข้ามไม้นั้น

เครื่องยนต์ทั้ง 3 ตัวทำงานอิสระ (magic 889000 / 889001 / 889002) ถือไม้พร้อมกันได้สูงสุด 3 ไม้

## แดชบอร์ด
- หัวหุ่นยนต์: ตาเขียว = ทำงาน, ส้ม = หยุดชั่วคราว, แดง = หยุดเพราะ DD ถึงเพดาน
- ปุ่มโหมด / ปุ่มความเสี่ยง: กดเปลี่ยนได้ทันที (จำค่าไว้แม้ปิด MT5) ใต้ปุ่มแสดงผลแบ็กเทสของตัวเลือกนั้น
- การ์ดบัญชี: ทุน, Equity, เท่ากับ USD (บัญชี Cent), กำไรวันนี้/เดือนนี้, แถบ DD เทียบเพดาน 50%
- การ์ดเครื่องยนต์ 3 ใบ: ถือ BUY/SELL/รอ, lot และกำไรลอย, สถานะ SSL และ D1, ระยะ SL, เหตุการณ์ล่าสุด
- ผลงาน + 5 ไม้ล่าสุด, ปุ่มหยุดชั่วคราว (ไม่เปิดไม้ใหม่ ไม้เดิมยังปิดตามสัญญาณ) และปุ่มปิดทุกไม้

## การติดตั้ง
1. เปิดกราฟ XAUUSD (บัญชี Cent: XAUUSDc) ใน MT5 บน VPS TF ใดก็ได้ ลาก EA ใส่ เปิด Algo Trading
2. บัญชี Cent แนะนำ เพราะ SL กว้าง $7–27 บัญชี Standard $300 จะเข้าไม้ได้น้อยมาก (0.01 lot เสี่ยงเกิน 5.5%)
3. เริ่มด้วยโหมดมาตรฐาน ความเสี่ยงกลาง บน demo 4–8 สัปดาห์ ก่อนใช้เงินจริง
4. EA เขียนบันทึก `MQL5/Files/xau_sentinel_trades.csv` ส่งให้ Claude ตรวจด้วย `compare_demo.py`
5. ถ้า DD ถึง 50% EA ปิดทุกไม้และหยุด เริ่มใหม่: ลบ Global Variable `XSN_889000_halt` (F3)
