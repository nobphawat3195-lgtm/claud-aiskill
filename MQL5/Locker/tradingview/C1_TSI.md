# True Strength Index (TSI) — เกรด A (สถิติ) แต่ไม่ช่วยพอร์ต

**ที่มา:** TradingView built-in · ค้นชื่อ "True Strength Index"
**ตรรกะ (ที่พอร์ตมาทดสอบ):** EMA13(EMA25(momentum)) / EMA13(EMA25(|momentum|)) × 100 · สัญญาณ = TSI ตัด EMA13 ของตัวเอง
**ค่าที่ใช้ (ค่าเดิมของผู้สร้าง):** 25 / 13 / 13
**TF ที่ดีที่สุด:** H1 (99.8%) แต่ปีก่อนแทบไม่ได้กำไร
**ใช้ใน EA:** ไม่ใช้ (ใส่เข้า QUARTET แล้วแย่ลงมาก)
**โค้ด:** MQL5 `—` · Python `tsi() ใน ind11.py` (`locker_indicators.py` / `MQL5/Research/xau_daytrend/`)

## ผ่านเกณฑ์ยังไง
1. ใช้ค่าเดิมของผู้สร้าง ไม่ได้ปรับให้เข้ากับข้อมูล
2. **สุ่มทิศ 2 ปี ≥ 95%**: สลับ Buy/Sell แบบสุ่ม 3,000–10,000 รอบ ผลจริงต้องชนะ ≥ 95% (พิสูจน์ว่าไม่ได้กำไรเพราะทองขึ้นอย่างเดียว)
3. บวกทั้งปีก่อนและปีล่าสุด
4. เกรด A = ฝั่ง Buy และ Sell บวกทั้งคู่ + สุ่มทิศ ≥ 99.5% · B = ผ่านแต่มีข้อสังเกต · C = พึ่งฝั่ง Buy
5. ก่อนใส่ใน EA: วัดความสัมพันธ์กับเครื่องยนต์เดิม + จำลองเงิน Cent $300 แบบ DD เท่ากัน ต้องได้กำไรมากขึ้น
