## ผ่านเกณฑ์ยังไง
1. ใช้ค่าเดิมของผู้สร้าง ไม่ได้ปรับให้เข้ากับข้อมูล
2. **สุ่มทิศ 2 ปี ≥ 95%**: สลับ Buy/Sell แบบสุ่ม 3,000–10,000 รอบ ผลจริงต้องชนะ ≥ 95% (พิสูจน์ว่าไม่ได้กำไรเพราะทองขึ้นอย่างเดียว)

4. เกรด A = ฝั่ง Buy และ Sell บวกทั้งคู่ + สุ่มทิศ ≥ 99.5% · B = ผ่านแต่มีข้อสังเกต · C = พึ่งฝั่ง Buy
