# XAU300_ORB_Research — ผลรอบที่ 1 (Python reference เท่านั้น ยังไม่มีผล MT5 ของ EA ตัวนี้)

**สถานะ: RESEARCH-ONLY** ตัวเลขในไฟล์นี้มาจาก simulator Python (`sim/orb15_sim.py`) บน Dukascopy M1 BID ใช้ spread คงที่ $0.28
**ห้ามนำไปอ้างเป็นกำไรใน MT5** เหตุผลมี 3 ข้อ:
- feed ของ MT5 (XAUUSD_DUKA) ใช้ bid/ask ที่เปลี่ยนตลอดและมี random delay ไม่ใช่สเปรดคงที่ $0.28
- Python เห็นราคาแค่ระดับแท่ง M1
- 1R ของ logic นี้เล็ก (ค่ากลาง $7.1 ต่อ 0.01 lot) จึงไวต่อสเปรดและ slippage มาก

ผล MT5 real tick ของ EA ตัวนี้ยังไม่มี รอผลจากเครื่องผู้ใช้

## ตัวเลขอ้างอิง MT5 ที่ต้องอ่านอย่างระวัง
- **ORB upstream ต้นฉบับ** บน XAUUSD_DUKA real tick (ผู้ใช้รันเอง ไม่ใช่ EA ตัวนี้) ได้ 42 ไม้, +$1.77, PF 1.01, equity DD 19.50%
- ผลชุดนี้ **ตั้ง timezone ผิด** คือใช้ `InpWinterOffset=0` กับ `InpFollowsUSDST=false` ซึ่งทำให้ใช้กติกา EU DST กรอบจึงเลื่อนไป +1 ชั่วโมงในฤดูร้อน ไม่ได้อยู่ที่ 00:00 UTC ตลอดปี **ห้ามใช้ตัวเลขนี้ตัดสิน logic** ผู้ใช้กำลังรันใหม่ด้วย `InpTimeZone=TZ_BROKER`
- ผล Python แบบเลียนต้นฉบับ (กรองรายวัน 0.14%, risk 2% ปัด lot ใกล้สุด) ได้ 81 ไม้, PF 2.21 ยังเทียบกับ MT5 ไม่ได้จนกว่าจะได้ผลที่ตั้ง timezone ถูก
