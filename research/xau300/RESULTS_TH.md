# XAU_300_Research_v1 — ผลรอบที่ 1 (Python reference, ยังไม่ใช่ MT5)

**สถานะ: RESEARCH-ONLY** ยังไม่มี positive edge ที่ผ่านเกณฑ์ ห้ามเรียกว่า ready หรือทำกำไรได้จริง
ตัวเลขทั้งหมดในไฟล์นี้มาจาก simulator Python (`sim/xau300_sim.py`) บน Dukascopy M1 BID ซึ่งเป็นค่าประมาณเชิงเปรียบเทียบเท่านั้น
หลักฐานจริงคือผล MT5 real tick (Model=4) จากเครื่องผู้ใช้ ซึ่งยังรอผลอยู่

## ข้อมูลที่ใช้ (coverage)
- **ข้อมูล:** Dukascopy XAUUSD BID M1 รายวัน ช่วง 2025-10-01 → 2026-10-30 23:59 UTC รวม 485,280 แท่ง ต.ค. 2025 ใช้เป็น warm-up ให้ kill filter เท่านั้น
- **ช่วงทดสอบ:** 2025-10-31 → 2026-10-31
- **ข้อมูลที่ขาด:** 2026-10-11 และ 2026-10-25 ทั้งสองวันเป็นวันอาทิตย์ (ตลาดเปิดราว 2 ชั่วโมง) ส่วน hash รายวันอยู่ใน `results/data_manifest.csv` ใช้เทียบว่าเครื่องอื่นใช้ข้อมูลชุดเดียวกันหรือไม่
- **ต้นทุน:** spread คงที่ $0.28 ไป-กลับ คิดฝั่ง ask, ไม่มี commission, ไม่มี swap เพราะ EA ปิดไม้ 21:00 ก่อน rollover, contract 100 oz, min lot 0.01, step 0.01
- **เวลา:** UTC ซึ่งเท่ากับ server GMT+0 ถ้าใช้โบรกเกอร์ GMT+2/+3 ต้องเลื่อน `InpRangeStartHour`, `InpEntryEndHour`, `InpExitHour` ให้ตรงกัน

## ผลตามกฎที่ล็อกไว้
1. **Best preset (net สูงสุด ภายใต้ DD ≤ 20% และไม่ halt):** P1/P2 ได้ net $0 เพราะไม่ได้เทรด ส่วน P3 ไม่ผ่าน (halt, DD 21.6%) → **ไม่มี preset ที่สร้างกำไรภายใต้ risk limit บนทุน $300**
2. **Entry edge (E0):** t(R) 2.65 ผ่าน แต่ PF 1.30 < 1.5 และครึ่งแรกติดลบ → **ไม่ผ่าน** edge กระจุกอยู่ใน พ.ค.–ก.ย. 2026 ซึ่งเป็นช่วงที่ทองผันผวนผิดปกติ ตรงกับคำเตือนใน Doc §1
3. **Acceptance (Doc §2):** ไม่ผ่านทุก preset
4. **ไม่เพิ่ม risk แล้วอ้างว่า logic ดีขึ้น:** ทั้ง 4 configs ใช้ entry ชุดเดียวกัน ต่างกันแค่ sizing
